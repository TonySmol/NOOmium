# 🧠 NOOmium
### *Умная лента - second brain без алгоритма-надзирателя*

> Мысли ищутся по значению, а не по словам.

---

## 📌 О проекте

**NOOmium** — это смысловой движок для работы с мыслями, который не держит вас на крючке внимания, а помогает находить созвучные идеи.

В отличие от привычных лент, где алгоритмы цепляют вас за сенсорные якоря, здесь всё строится на **семантической близости**. Вы пишете «дождь за окном успокаивает» — NOOmium находит мысль незнакомца о тишине ночного города. Не по словам. По **смыслу**.

---

## ✨ Ключевые принципы

| Принцип | Суть |
|---------|------|
| **Смысл > Слова** | Каждая мысль — вектор в пространстве смыслов. Поиск по близости, а не по ключевым словам. |
| **Privacy by Design** | Модель, поиск, хранение — **локально**. Никакой сервер не читает ваши мысли. |
| **Вы — не профиль** | Криптография вместо регистрации. Ключ — это вы, а не строка в чужой базе. |
| **Вы управляете лентой** | Пороги, режимы, диапазоны настраиваются локально. Без внешнего влияния. |
| **Офлайн — норма** | В самолёте, метро, лесу — заметки и поиск работают всегда. |

---

## ⚙️ Как это работает

1. **Пишите**  
   Мысль превращается в вектор — точку в пространстве смыслов.

2. **Ищете**  
   Начинайте печатать — лента мгновенно фильтруется по смыслу.

3. **Пин**  
   Клик по мысли — и она становится контекстом. Лента показывает всё созвучное.

4. **Дрейф**  
   Печатайте при пине — контекст плавно смещается к вашему тексту.

5. **Мир**  
   Отправьте мысль в сеть — её найдут другие по смыслу.

6. **Резонанс ◆**  
   Показывает, сколько мыслей породила ваша.

7. **Генеалогия ↳**  
   Ведёт к источнику мысли, шаг за шагом.

8. **Источник ↩**  
   Оригинал (для мыслей из Telegram-каналов).

---

## 🛡 Безопасность и архитектура

- **Модель на устройстве**  
  ИИ работает локально — никто не читает ваши тексты.

- **Шифрование**  
  Личное зашифровано по **NIP-44 (ECDH + AES-GCM)** — видите только вы.

- **Нет сервера-посредника**  
  Сеть — **Nostr-протокол**, публичные релеи, без центрального владельца.

- **Ключ — единственный вход**  
  Потеряли ключ — доступ потерян навсегда. ⚠️ Сохраните его сразу после регистрации.

---

## 🚀 Начало работы

1. Откройте **NOOmium** в браузере или Telegram.
2. Меню → «Установить приложение».
3. Дождитесь загрузки модели **(~97 МБ, однократно, дальше из кэша)**.
4. Сохраните ключ: «Аккаунт и ключ» → Показать.
