NOOmium
Умная лента без алгоритма-надзирателя
Мысли ищутся по значению, а не по словам.

License

Зачем это
Обычная лента показывает то, что удержит твоё внимание. Чем дольше — тем лучше для платформы.

NOOmium показывает то, что близко твоей мысли. Чем точнее — тем лучше для тебя.

Ты пишешь «дождь за окном успокаивает» — NOOmium найдёт мысль незнакомого человека о тишине ночного города. Не потому что совпали слова.Потому что совпал смысл.

Принципы
Смысл важнее слов	Каждая мысль — вектор в пространстве смыслов. Поиск — по близости, не по ключевым словам
Всё у тебя на устройстве	Модель, поиск, хранение — локально. Никакой сервер не читает твои мысли
Ты — не профиль	Криптография вместо регистрации. Ключ это ты, а не строка в чьей-то базе
Лента не рулит тобой	Пороги, режимы, диапазоны — настраиваешь сам, всё локально
Офлайн — норма	Самолёт, метро, лес — заметки и поиск работают всегда
Как это работает
Пишешь	Мысль становится вектором — точкой в пространстве смыслов
Ищешь	Начни печатать — лента фильтруется по смыслу, мгновенно
Пин	Клик по мысли — она станет контекстом. Лента покажет всё созвучное
Дрейф	Печатай при пине — контекст плавно уходит к твоему тексту
Мир	Отправь мысль в сеть — её найдут другие по смыслу
Резонанс	◆ покажет, сколько мыслей породила твоя
Генеалогия	↳ ведёт к источнику мысли, шаг за шагом
Источник	↩ — оригинал (для мыслей из Telegram-каналов)
Безопасность
Модель на устройстве	ИИ работает локально — никто не читает тексты
Личное зашифровано	NIP-44 (ECDH + AES-GCM) — видишь только ты
Нет сервера-посредника	Сеть — Nostr-протокол, публичные релеи, без центрального владельца
Ключ — единственный вход	Потерял ключ — никто не восстановит. Сохрани его
⚠ Ключ невосстановим. Никто не сможет вернуть тебе доступ. Экспортируй ключ в «Аккаунт и ключ» сразу после регистрации.

Начать
Открой NOOmium в браузере или Telegram
Меню → «Установить приложение»
Дождись загрузки модели (97МБ, один раз, дальше из кэша)
Сохрани ключ — «Аккаунт и ключ» → Показать
Технически
PWA + Telegram Mini App. Модель ИИ (97МБ, Granite-embedding) — на устройстве. Хранение — IndexedDB. Сеть — Nostr (публичные релеи, NIP-44). Без сервера. Код открыт: Apache 2.0.
