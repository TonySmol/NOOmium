NOOmium
Соцсеть смыслов.
Мысли ищутся по значению, а не по словам.

Зачем
Лента в обычной соцсети показывает то, что удержит твоё внимание. Чем дольше — тем лучше. NOOmium показывает то, что близко твоей мысли. Чем точнее — тем лучше.

Ты пишешь «дождь за окном успокаивает» — NOOmium найдёт тебе мысльне знакомого человека о тишине ночного города. Не потому что совпали слова. Потому что совпал смысл.

Что это
Умная лента — приложение для телефона и Telegram, которое:

ищет мысли по смыслу, а не по ключевым словам
работает без сервера — вся логика у тебя на устройстве
без регистрации — твой ключ это ты
без алгоритма-надзирателя — ты настраиваешь что и как искать
работает офлайн — заметки и поиск всегда с тобой

Как
Пишешь	Мысль становится вектором — точкой в пространстве смыслов
Ищешь	Начни печатать — лента фильтруется по смыслу, мгновенно
Пин	Клик по мысли — она станет «мамой»: лента покажет всё созвучное
Дрейф	Печатай при пине — контекст плавно уходит к твоему тексту
Мир	Отправь мысль в сеть — её найдут другие по смыслу
Резонанс	◆ покажет, сколько мыслей породила твоя

Почему это безопасно
Модель на устройстве	Никто не читает твои мысли — ИИ работает локально
Ключ — не логин	Криптография вместо пароля. Потерял — никто не восстановит
Личное зашифровано	Приватные заметки закрыты NIP-44 — видишь только ты
Нет сервера-посредника	Удалить полностью — удали с релеев, ключ остаётся у тебя
Офлайн	Самолёт, лес, метро — заметки и поиск работают всегда

Начать
Открой NOOmium в браузере или Telegram боте t.me/noomium_bot
Меню → «Установить приложение» (на домашний экран)
Дождись модели (~97МБ, один раз)
Сохрани ключ — «Аккаунт и ключ» → Показать → Скопировать
⚠ Ключ невосстановим. Потерял — потерял мысли. Сохрани его надёжно.

Что внутри
Всё работает в браузере, без сервера. Модель ИИ (97МБ) — локально. Хранение — IndexedDB на устройстве. Сеть — Nostr-протокол, публичные релеи, end-to-end шифрование. Код открыт (Apache 2.0).
